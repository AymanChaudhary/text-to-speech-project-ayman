# 🔊 Text to Speech Website 🔊

A simple Text to Speech website created by Ayman Reza Chaudhary, where you can input a text and get an output as a voice. It works as an ElevenLabs, Speechma, Minimax Audio, etc. prototype.

Languages Used:
- React.js (Frontend)
- Node.js (Backend)
- Express.js (Backend)

Here, WebSpeech API is used which is absolutely free of cost. But with the limitations of Limited number of voices and languages.
